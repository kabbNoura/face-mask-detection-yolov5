# Face Mask Detection Using YOLOv5

A computer vision project for real-time face mask detection, with model training in Google Colab, local testing, and integration into a car prototype.

## Overview

The project uses YOLOv5 to detect face mask use in camera images. The trained model is used for local testing and was also integrated into a car prototype by Nabil Houssain.

## Technologies

- Python
- YOLOv5
- Google Colab
- Jupyter Notebook
